Solidus RPC API

JSON-RPC 2.0 endpoint for the Solidus blockchain testnet. Query accounts, submit transactions, resolve DIDs, and verify credentials.

https://rpc.solidus.network

Quick Start

Send your first request with curl:

curl -X POST https://rpc.solidus.network \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","method":"solidus_getLatestBlock","params":[],"id":1}'
Accounts
solidus_getBalance Get account balance in smallest units (1 SOLID = 10^8)

Parameters

NameTypeDescription
addressstringAccount address

Returns

u64

Example Request

{
  "jsonrpc": "2.0",
  "method": "solidus_getBalance",
  "params": ["LCpx9S99Juc9qBHk9RudCQDnwEK"],
  "id": 1
}
